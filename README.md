# 悦足堂 · 连锁足浴总部门店管理平台

面向连锁足浴品牌的一体化运营系统：**总部统一定价/会员/提成标准 → 门店每日上钟录单 → 交班双签字确认 → 营收自动汇总至总部看板**。零外部运行依赖（Node 内置 HTTP + JSON 文件持久化，图表/签字板均为原生实现）。

## 快速开始

```bash
npm start
# 打开 http://localhost:3000
```

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 总部 | `hq`（或 `boss`） | `123456` |
| 门店 | `s01` ~ `s06`（如 `s01` 外滩店、`s04` 北京国贸店） | `123456` |

其他命令：

```bash
npm run seed          # 重置为内置演示数据（6 店 / 65 技师 / 45 天 5487 笔账单 + 库存演示数据）
node test-e2e.js              # 后端业务流 API 测试（需先 npm start）
node test-inventory.js        # 库存业务流测试：原子扣减/幂等/调拨冻结解冻/盘点/越权（需先 npm start）
node test-inventory-dom.js    # 库存前端视图渲染烟雾测试（无需服务、无需 jsdom）
node test-dom.js      # 总部端页面集成测试（需先 npm i jsdom --no-save 且 npm start）
node test-dom-store.js# 门店端开单→双签字交班集成测试
```

数据存储于 `data/db.json`，删除后重启会自动重新生成种子数据。

## 功能总览

### 总部端
- **品牌经营看板**：全品牌总营收/客单价、会员充值总额（含赠金/卡内余额）、提成总额；各门店营收排行 TOP 榜；品类与项目销售占比环形图；近 7/30/45 天日营收趋势。
- **项目统一定价**：项目目录（时长/价格/品类/上下架），调价后所有门店即时生效；历史账单保留原价不受影响。
- **会员体系**：四级会员（银/金/铂金/至尊）门槛与折扣统一配置；充值满 3000 自动赠 10%，累计充值自动升级。
- **技师提成标准**：四个技师等级默认提成比例（25%~40%）可调；支持「项目 × 等级」专项规则（每单固定金额或自定义比例），优先级高于默认比例，开单时实时计算并展示提成依据。
- **门店管理**：门店档案、新增/编辑。
- **技师档案（全品牌）**：入职登记（培训考核记录、证书、擅长项目多选）、离职、跨店调动；调动记录独立留痕。
- **全品牌流水**：跨店账单流水、全部门店交班记录、会员充值流水。

### 总部 · 耗材库存
- **耗材目录**：统一维护耗材、计量单位、安全库存与启停（停用保留历史流水）；支持自定义单位。
- **标准耗用配方**：按服务项目配置每单耗材用量，全部门店新开单实时生效，历史账单与已扣库存不受影响。
- **总部库存总览**：各门店实时库存（账面/冻结/可用）、低库存预警、30 天内临期与已过期批次、在途调拨，可下钻单店批次明细。
- **全品牌出入库流水**：入库/开单耗用/盘盈盘亏/冻结/解冻/调入调出全类型、按门店/耗材/类型/日期/关键字查询。

### 门店 · 耗材库存
- **库存工作台**：本店 SKU 账面总量/冻结量/可用量、低库存/临期/过期预警、调拨待办、批次明细、跳转入库/盘点/调拨。
- **批次入库**：每条明细生成独立批次（含供应商、生产日期、到期日），支持多耗材一次入库；提交幂等。
- **库存盘点**：服务端生成账面快照（单列冻结量），录入实盘数后盘盈生成盘盈批次、盘亏按 FEFO 扣减；未提交可作废。
- **跨店调拨**：主动调出（本店选批次）/向他店请货（对方确认时自动 FEFO 分配）；调出店确认即冻结，调入店签收后才完成扣增；可拒绝/取消并正确解冻；确认与签收均幂等。
- **开单联动**：试算时展示本单耗材与可用量，不足直接禁用提交；提交携带幂等键，防重复扣减。
- **本店流水**：仅本店出入库流水可查。

### 门店端
- **门店看板**：周期/今日营收、本班次实时收款汇总（现金/刷卡/会员卡/移动支付）、趋势、品类占比、近期交班记录、一键开班。
- **上钟开单**：选择项目（自动带出总部定价）→ 技师（仅本店在职）→ 可选会员（自动折扣并校验卡内余额）；金额、折扣、技师提成实时试算；账单实时归入当前班次。
- **交班结算**：自动生成交班报表（本班接待人数、现金/刷卡/会员卡/移动支付分项、营收与提成合计、技师上钟明细）；**交班人与接班人必须在手写签字板上分别签名**方可完成交班，报表即时同步总部，支持历史回看签名。
- **技师业绩提成**：按日期区间统计每位技师上钟单数、服务时长、营收、应发提成并排名。
- **员工管理**：本店技师入职登记、考核记录追加、擅长项目维护、离职、调动到其他门店。
- **会员管理**：开卡、充值（自动赠金升级）、充值记录查询。

## 关键业务规则
- 提成计算：专项规则（项目+等级，固定额/比例）> 技师等级默认比例；每笔订单落库当时的实付与提成，事后调整标准不改历史数据。
- 会员单只能使用会员卡余额支付，余额不足直接拒绝；折扣按会员等级计算。
- 同一门店同时只允许一个进行中的班次；已交班班次不能再录单、不能重复交班。
- 门店账号只能操作本店数据（技师/会员/班次/账单/库存/批次/盘点/调拨/流水均有后端越权校验）。
- 交班签字以 dataURL 图片持久化，双方签名缺一不可。
- **库存原子扣减**：开单先按配方 + FEFO（临期优先，无到期日排最后）生成全量批次分配计划，任一耗材不足即 409 整单失败——账单、会员余额、批次库存均不产生任何变动；提交段在同一同步调用栈内完成，落库前不等待 I/O。
- **幂等**：开单/入库以 `clientReqId` 去重；调拨确认/拒绝/取消/签收与盘点确认为状态机幂等，重复提交返回首张单据，冻结/解冻/扣增不重复发生。
- **调拨状态机**：`pending →（调出店确认）→ frozen（批次冻结）→（调入店签收）→ received（调出扣减 + 调入新批次）`；pending 可拒绝（无批次变动）；frozen 可由调入店取消（释放冻结，写解冻流水）。已过期批次不参与可用量与 FEFO 分配。

## 技术结构
```
server/
  index.js      HTTP 服务 + REST API + 鉴权 + 聚合统计（零依赖）
  db.js         JSON 持久化 + 确定性演示数据生成（含库存种子）
  inventory.js  耗材库存领域模块：FEFO 批次、原子耗用、调拨状态机、盘点、流水
public/
  index.html 单页外壳
  css/app.css              品牌主题样式
  js/
    api.js         fetch/token 封装
    ui.js          DOM/弹窗/toast/格式化
    charts.js      纯 SVG 面积图、环形图、排行榜
    signature.js   canvas 手写签字板（鼠标/触摸）
    hq.js          总部视图（技师档案/交班明细等共享函数）
    store.js       门店视图（开单页已接入耗材配方试算与幂等提交）
    inventory-hq.js    总部库存总览/耗材与配方/流水视图
    inventory-store.js 门店库存工作台/入库/盘点/调拨/流水视图
    app.js         登录、布局、哈希路由
```
